# 🧾 Python SQLite Auth System

Это мой учебный проект на Python, где я сделал простую систему регистрации и входа через консоль.  
Данные хранятся в SQLite базе.

Делал этот проект чтобы лучше понять:
- как работают базы данных
- как устроена авторизация
- как вообще строится логика пользователей в программах

---

## ⚙️ Что умеет программа

- 📝 регистрация пользователя (имя, почта, телефон, пароль)
- 🔑 вход в аккаунт по почте или номеру телефона
- 🔐 простая "защита" пароля (кодировка через ASCII)
- 👤 роли пользователей (user / admin)
- 🛠️ админ может смотреть базу и менять роли

---

## 🧠 Как это работает

При регистрации пароль превращается в набор чисел (ASCII-коды) и сохраняется в базе.

При входе он обратно декодируется и сравнивается с тем, что ввёл пользователь.

Если всё совпало — пользователь входит в аккаунт.

---

## 🛠️ Используемые технологии

- 🐍 Python
- 🗄️ SQLite3 (встроенная база данных)

---

## 📦 Основные функции

- `registration()` — регистрация пользователя  
- `login()` — вход в систему  
- `create_db()` — создание базы данных  
- `show_db_info()` — просмотр данных  
- `on_programm()` — главное меню программы  

---

## 👥 Роли пользователей

- 👤 **user** — обычный пользователь (вход и базовые действия)
- 🛡️ **admin** — администратор (может смотреть базу и менять роли)
